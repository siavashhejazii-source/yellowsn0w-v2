YellowSn0w Legacy Cydia Repository

This is a flat APT repository containing yellowsn0w 0.9.6.

Files to publish at the repository web root:
  Release
  Packages
  Packages.gz
  yellowsn0w_0.9.6.deb

After publishing, the Cydia source URL is the HTTPS URL of that web root,
for example: https://YOURNAME.github.io/yellowsn0w-repo/

Compatibility note:
This package targets the historical iphoneos-arm environment. Hosting the
repository does not verify package authenticity, package safety, or successful
installation/unlocking on a particular iPhone or firmware. Test only on a
backup device and retain a way to restore the phone.
